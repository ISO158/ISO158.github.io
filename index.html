IoT & Hardware

Spin Coater DIY & Instrumentação de Precisão

ESP32 C++ Modelagem 3D Impressão 3D OriginPro

Projeto completo de engenharia e instrumentação científica: desenvolvi do zero um spin coater (dispositivo para deposição de filmes finos) voltado para experimentos de biofísica em laboratório.

A solução integra hardware customizado (modelagem e impressão 3D do chassi e suportes), firmware em C++ para ESP32 controlando velocidade de rotação com precisão, e software de aquisição para monitoramento em tempo real.

A calibração do sistema foi validada com análise estatística da relação PWM vs. RPM (gráfico acima), utilizando OriginPro para ajuste de curvas e visualização. O diagrama do circuito elétrico documenta toda a arquitetura de controle, garantindo reprodutibilidade experimental.

Data Science & IA

Pipelines de Deep Learning para Dados de Biofísica

Python PyTorch SciPy OriginPro LaTeX

Desenvolvi pipelines completos de processamento de sinais espectroscópicos utilizando redes neurais profundas (PyTorch) para automatizar a deconvolução de picos sobrepostos, um problema clássico e desafiador em experimentos de fluorescência e dinâmica de membranas lipídicas.

O fluxo inclui: pré-processamento estatístico dos espectros com SciPy/NumPy, normalização robusta, treinamento de modelos probabilísticos para estimar parâmetros físicos (largura de banda, centroide, intensidade relativa), e validação cruzada contra ground truth experimental.

Toda a documentação matemática e os resultados foram compilados em LaTeX para publicação, e as visualizações analíticas foram geradas com OriginPro, garantindo comunicação científica de alto nível.

Cloud & Inteligência Artificial

Agentes IA Autônomos e Soluções Cloud na Azure

Azure AI LLMs Python OCR RAG

Arquitetura e implementação de agentes autônomos de IA sobre a plataforma Microsoft Azure (AI Foundry), combinando Large Language Models, busca vetorial semântica (RAG) e serviços cognitivos de OCR para processamento inteligente de documentos.

Os agentes foram projetados para executar tarefas complexas em pipeline: ingestão de documentos não estruturados, extração de entidades, classificação contextual e geração de respostas fundamentadas em bases de conhecimento proprietárias, tudo orquestrado em Python com APIs nativas da Azure.

Este projeto demonstra minha capacidade de integrar tecnologias de ponta em IA generativa com infraestrutura Cloud empresarial, entregando soluções escaláveis e prontas para produção.
